## 📝 Issue Reporting Guidelines

When reporting new issues, please include:

1. **Clear Description**: What is the expected vs actual behavior?
2. **Steps to Reproduce**: How can we reproduce the issue?
3. **Environment Details**: 
   - Operating System
   - Browser (if web-related)
   - Jekyll version (if build-related)
4. **Screenshots**: If applicable, include screenshots
5. **Priority Level**: High/Medium/Low based on impact

## 🔄 Issue Lifecycle

- **🔍 Under Investigation**: Issue reported, being analyzed
- **📋 Confirmed**: Issue verified and documented
- **🚧 In Progress**: Work has started on fixing the issue
- **✅ Fixed**: Issue resolved and tested
- **❌ Won't Fix**: Issue determined to be out of scope or not a bug

## 📊 Priority Levels

- **High**: Critical functionality broken, blocks users
- **Medium**: Important feature not working as expected
- **Low**: Nice-to-have improvements, minor issues
