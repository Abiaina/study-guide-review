## Pattern Recognition Guide

### When to Use Each Pattern

- **Sliding Window**: Subarray/substring problems, longest/shortest with constraints
- **Two Pointers**: Sorted arrays, palindromes, merging sorted data
- **Fast & Slow Pointers**: Linked lists, cycle detection, finding middle/k-th node
- **Prefix / Suffix**: Range queries, subarray sums, cumulative information
- **Greedy**: Interval scheduling, optimization with local choices
- **Binary Search**: Sorted data, optimization problems, search space reduction
- **Backtracking**: Generate all combinations/permutations, constraint satisfaction
- **Dynamic Programming**: Overlapping subproblems, optimization with choices
- **Monotonic Stack**: Next/previous greater/smaller element problems
- **Graph Traversal**: Path finding, cycle detection, connectivity problems
- **Heap**: K-th largest/smallest, top-K problems, priority-based scheduling
- **Greedy Threshold Tracking**: Increasing sequences, multiple candidate tracking
- **Hash Map / Frequency Tracking**: Fast lookup, counting, grouping, prefix sums
- **Intervals**: Time ranges, scheduling, merging overlapping ranges
